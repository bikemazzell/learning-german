# German Irregular Verbs - Mnemonic Study System

## How to Use This List

Each mnemonic's vowels indicate the stem changes for **Praeteritum** and **Perfect**:
- **InkA** → Praeteritum uses "i" or "ie", Perfect uses "a"
- **bArrEl** → Praeteritum uses "a", Perfect uses "e"
- **sAUdi** → Praeteritum uses "a", Perfect uses "u"
- **UsA** → Praeteritum uses "u", Perfect uses "a"
- **lAssO** → Praeteritum uses "a", Perfect uses "o"
- **pOlO** → Both Praeteritum and Perfect use "o"
- **wInd** → Infinitive "ei" changes to "ie" or "i" in both forms
- **anAcondA** → Mixed patterns (consonant changes, weak endings)

**Frequency**: ★★★ = Essential | ★★☆ = Common | ★☆☆ = Less common

**Note**: Verbs with inseparable prefixes (be-, emp-, ent-, er-, ge-, ver-) don't add "ge-" in Perfect.

## Quick Reference Card

| Mnemonic | Pattern | Memory Aid |
|----------|---------|------------|
| **INKA** | → I/IE, → A | **I**nca: Praet gets **i/ie**, Perfect gets **a** (schl**ie**f → geschl**a**fen) |
| **BARREL** | → A, → E | Roll from **A** to **E** (s**a**h → ges**e**hen) |
| **SAUDI** | → A, → U | Desert **A** becomes oasis **U** (tr**a**nk → getr**u**nken) |
| **USA** | → U, → A | **U**SA drives to **A**merica (f**u**hr → gef**a**hren) |
| **LASSO** | → A, → O | Cowboy catches **A**, ties **O** (spr**a**ch → gespr**o**chen) |
| **POLO** | → O, → O | Double **O** - horse goes **O**-**O** (fl**o**g → gefl**o**gen) |
| **MIRROR** | EI ↔ IE/I | **EI** mirrors to **IE** (bl**ei**ben→bl**ie**b) or shrinks to **I** (r**ei**ßen→r**iss**) |
| **ANACONDA** | Mixed | Tricky snake - consonant changes, weak endings |

## Notes

- **No ge- prefix**: Verbs starting with be-, emp-, ent-, er-, ge-, ver-, zer- don't add "ge-" in Perfect:
  - empfehlen → empfohlen (not ~~ge~~empfohlen)
  - verlieren → verloren
  - beginnen → begonnen
  - gewinnen → gewonnen
  - genießen → genossen
  - gelingen → gelungen
  - vermeiden → vermieden
  - verzeihen → verziehen

- **Total**: 97 irregular verbs organized into 8 mnemonic groups across 4 learning phases
